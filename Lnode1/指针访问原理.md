
 指针是一个地址 为什么可以 访问成员变量?
指针本身确实只是一个地址，它并不是成员变量。之所以可以通过指针访问成员，是因为编译器知道结构体的内存布局。

  例如：

  struct Books {
      char title[50];
      int book_id;
  };

  struct Books book;
  struct Books *p = &book;

  此时：

  p
  │
  └──> book 的起始地址
        ┌────────────────┐
        │ title          │
        ├────────────────┤
        │ book_id        │
        └────────────────┘

  结构体各成员在内存中的位置是固定的。编译器知道：

  - title 位于结构体起始位置
  - book_id 位于起始地址之后某个固定偏移量

  因此：

  p->book_id = 6495700;

  编译器会理解为：

  (*p).book_id = 6495700;

  可以分成两步：

  *p

  先根据地址找到完整的 struct Books 对象。

  (*p).book_id

  再访问这个结构体对象的 book_id 成员。

  所以：

  p->book_id

  就是：

  (*p).book_id

  其中：

  - .：结构体变量访问成员
  - ->：结构体指针访问成员

  例如：

  struct Books book;
  book.book_id = 100;

  等价于：

  struct Books *p = &book;
  p->book_id = 100;

  但前提是指针必须指向有效的结构体对象：

  struct Books *p;  // 未初始化，不能直接 p->book_id

  正确方式：

  struct Books book;
  struct Books *p = &book;

  p->book_id = 100;

  可以把指针理解成“地址导航信息”：它先带你找到整个结构体，编译器再根据结构体定义找到对应成员的位置。
